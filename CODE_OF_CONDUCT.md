# Code of Conduct

## Scope

This code applies to repository issues, pull requests, discussions, review comments, and project communication channels.

## Expected Behavior

- keep technical disagreement focused on evidence and project goals
- respect privacy and do not post private recordings, transcripts, screenshots, credentials, tokens, or personal data
- avoid harassment, threats, insults, and discriminatory language
- accept maintainer decisions on scope, safety, privacy, and release readiness

## Unacceptable Behavior

- public disclosure of security issues before maintainers have a private report
- posting secrets, private user data, or exploit payloads in public threads
- repeated off-topic demands after a maintainer has closed the discussion
- abuse related to identity, background, disability, or experience level

## Enforcement

Maintainers may edit or delete comments, close issues or pull requests, block accounts, or report abuse to GitHub.

Report conduct problems privately to the repository owner through GitHub. Do not include unrelated private data in the report.
